# 에니어그램 웹사이트

에니어그램을 이해하고 → 유형을 비교하고 → 실제 경험을 기록하며 → 반복 패턴을 발견하는 자기이해 웹서비스 (로컬 프로토타입)

## 실행

- **Windows:** `start-server.bat` 더블클릭 → 브라우저에서 http://localhost:5500 이 열립니다.
- **직접 실행:** `node tools/dev-server.js --open`

파일을 저장하면 브라우저가 자동으로 새로고침됩니다. CSS만 바꾸면 새로고침 없이 스타일만 바뀝니다.
서버 없이 `index.html`을 더블클릭해도 열리지만, 이때는 자동 새로고침이 되지 않습니다.
