> 2. 그동안 정한 것을 반영했습니다: 모바일 웹 앱 폭 616px, 간편 검사 / 정식 검사 이름, 다이어리 테마 7종, 연마 처방전(로컬 규칙형)

> 4. MVP를 **A단계(서버 없이)** 와 **B단계(서버 필요)** 로 나눴습니다 (§13)

> **PRD vs RFP**
> - **PRD (Product Requirements Document, 제품 요구사항 문서)**: *무엇을, 왜, 누구를 위해* 만드는지 정의하는 내부 기획 문서. 이 문서입니다.
> - **RFP (Request for Proposal, 제안 요청서)**: 외주 개발사에 견적·제안을 받기 위해 보내는 문서. 외주를 맡기게 되면 이 PRD에서 파생합니다.

## 1. 한 줄 정의

**"내 안의 보석을 깨우고 닦아가는 마법 다이어리."**
에니어그램 유형을 9가지 보석으로 표현하고, 테마 다이어리와 피드백으로 마음 상태의 변화를 보여주며 성찰을 돕는 모바일 웹 서비스입니다.

## 2. 배경과 문제

- 에니어그램 검사는 많지만 대부분 **유형 결과를 한 번 보고 끝납니다**. 결과가 일상과 연결되지 않습니다.
- 같은 유형이어도 건강한 상태와 지친 상태의 모습은 크게 다릅니다(리소·허드슨 발달 수준). 그런데 이 **상태 변화**를 다루는 서비스는 드뭅니다.
- 일기 앱은 기록은 되지만 "그래서 나는 어떤 패턴이 있지?"에 답해주지 않습니다.

**기회**: 검사(진입) → 다이어리(습관) → 패턴 피드백(가치)로 이어지는 흐름을, 공유하고 싶어지는 비주얼로 감싸기.

## 3. 목표 / 비목표

### 목표
1. 무료 간편 검사 + 프로필 카드로 **유입과 공유(바이럴)** 를 만든다.
2. 유료 상세 검사 + 테마 다이어리로 **재방문 습관과 결제 전환**을 만든다.
3. 사용자가 "판정받았다"가 아니라 **"나를 더 알게 됐다"** 고 느끼게 한다.

### 비목표 (하지 않는 것)
- 의학적·임상적 **진단**. 정신건강 질환 여부를 판단하지 않는다. (§8)
- 상담·치료 서비스 대체.
- 다른 사람의 유형을 평가하거나 비교·순위 매기기. 커뮤니티의 장면 게임도 반응을 나란히 보여줄 뿐 궁합·점수는 매기지 않는다. (§7-12)
- 1단계에서의 네이티브 앱 출시 (모바일 웹으로 검증한 뒤 판단).

## 5. 디자인 컨셉

> 구체 규칙은 프로젝트 `CLAUDE.md`, `css/tokens.css`, `docs/UI_안티슬롭_가이드.md`, `docs/UX_라이팅_가이드.md`가 기준입니다.

### 5-1. 무드
- 마법소녀의 **"변신·각성" 구조**를 빌리되 겉모습은 **성별 중립**
  - 참고: 카드캡터 체리, 세일러문 / 포켓몬·디지몬의 진화, 원신의 "신의 눈", TCG 홀로그램 레어 카드
- 한 문장 톤: **"밤하늘 아래 빛나는 결정"**. 맑고 신비로운 쪽

### 5-2. 너무 여성향으로 가지 않기 위한 규칙

| 줄일 것 | 대신 쓸 것 |
|---|---|
| 핑크 중심 팔레트 | 라벤더·민트·스카이·피치를 고르게, 바탕은 흰색 |
| 리본, 하트, 레이스, 반짝이 남발 | 보석 단면(패싯), 기하학 패턴, 빛 굴절 |
| "소녀", "공주", "~했쪙" 같은 말투 | 성별 없는 다정한 존댓말, 보석·빛·결정 은유 |
| 여자 캐릭터 마스코트 | 사람 캐릭터 없이 **보석 자체가 주인공** |

검증: 시안 단계에서 **남성 사용자 3~5명에게 "써도 민망하지 않은지"** 짧게 확인 (5분 인터뷰). — ⬜ 아직 안 함

### 5-3. 컨셉을 기능에 녹이는 방법

| 변신·각성 요소 | 서비스 안에서 | 현황 |
|---|---|---|
| 각성 장면 | 검사 결과 공개: 뿌연 원석이 맑은 보석이 됨 | ✅ |
| 홀로그램 레어 카드 | 프로필 카드 (크리스탈 글래스) | ✅ 정적 그라데이션 |
| 유형별 보석 9종 | 사파이어 ~ 아쿠아마린 | ✅ |
| 아직 각성 전 | 상세 검사 전 = "다듬어지지 않은 원석" | ⬜ |
| 연마 | 다이어리 한 편 = 원석 하나를 연마, 결과 = 연마 처방전 | ✅ |
| 보석 닦기 | 해보기로 한 실천을 모아 닦는 곳 | ✅ |
| 보석의 빛 | 상태: 빛남 / 연마 중 / 흐려짐 | ⬜ |

### 5-4. 디자인 원칙
1. **귀엽되 가볍지 않게**: 성찰·감정 기록 화면은 장식을 줄이고 여백 확보.
2. **흐려짐은 벌이 아니다**: 흐린 보석도 예쁘게. 닦으면 다시 빛난다는 회복 메시지.
3. **그라데이션·홀로그램은 포인트로만**: 프로필·결과 카드, 홈 배너, 메뉴 아이콘 선. 바탕은 흰색.
4. **성별 중립**: §5-2.
5. **접근성**: 텍스트 명도 대비 WCAG AA 이상.
6. **펼치기·접기를 쓰지 않는다**: 내용은 펼쳐서 보여준다. (2026-10 결정)

### 5-5. 주의 (IP)
- 참고 작품의 캐릭터, 로고, 의상, 고유 아이템을 그대로 쓰지 않는다. 입체 이모지(Fluent Emoji 3D, MIT)와 사진(Unsplash)은 출처를 `CREDITS.md`에 남긴다.

### 7-7. 맞춤 솔루션
일기를 쓴 뒤 받는 피드백. **판정이 아니라 관찰 + 질문 + 작은 실천**.

## 8. 짚을 점: "정신건강 상태 진단"이라는 표현

(v1과 같음, 결론만 다시 적습니다.)

- "진단"은 의료행위로 읽힐 수 있어 의료법·의료기기 규제·과장 광고 문제 소지가 있고, 사용자가 실제 도움을 미룰 위험이 있습니다.
- 기능 이름은 **"보석 컨디션"** 또는 "마음 상태 리포트".
- 화면·마케팅 문구 전반에서 **진단, 치료, 정신건강 평가, 우울 점수** 금지. 대신 "지금 내 보석은 어떤 빛인지 살펴봐요", "요즘 반복되는 패턴".
- PHQ-9 같은 검증 척도는 MVP에서 제외. 넣는다면 별도 기능 + 전문가 자문 + 법률 검토.

## 9. 핵심 사용자 흐름

```
[유입] SNS에서 친구 프로필 카드 / 장면 게임 링크를 봄
   ↓
[무료] 간편 검사 (로그인 X, 3~5분) → 원석 → 보석 연출
   ↓
[무료] 프로필 카드 → 공유 / 유형 요약·콘텐츠 / 헷갈리면 정식 검사
   ↓ "지금 내 보석은 빛나고 있을까?"
[전환] 로그인 → 상세 검사 미리보기 (일부 블러)                 ← B단계
   ↓ 결제
[유료] 상세 검사 → 현재 상태 구간(범위)
   ↓
[습관] 테마 다이어리 → 5Why → 연마 처방전(→ AI 피드백) → 보석 닦기에 담기
   ↓ 매일/주 반복
[가치] 반복 패턴 알림, 주간·월간 회고, 보석 상태 변화
   ↓ 4주 후
[재측정] 상세 검사 재측정 → 변화 회고
```

## 10. 기술 요구사항
