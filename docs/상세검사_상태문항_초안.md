# 상세 검사 — 상태 문항 초안

> 이 문서는 **초안**이에요. 문항은 핸드북의 발달 수준 요약·일깨우는 신호·위험 신호·미성숙할 때의 모습·에너지 소진 항목을 참고해 **새로 쓴 문장**이에요 (PRD TY-2: 리소·허드슨 문장 직접 인용 금지).
> 에니어그램 자격 과정 자료로 내용 검수를 하고, 지인 파일럿(§7)으로 기준값을 맞춘 뒤 사이트에 넣어요.

## 1. 무엇을 재나

- 정식 검사가 **"나는 몇 번에 가까운가"**를 본다면, 상세 검사는 **"요즘 내 보석은 어떤 빛인가"**를 봐요.
- 유형을 정한 사람(간편·정식 검사 결과 또는 직접 고른 유형)만 자기 유형 문항을 풀어요.
- 결과는 숫자 레벨이 아니라 **세 구간 + 압박 속 경향**으로만 보여줘요 (DT-3).
  - 예: "요즘은 주로 **연마 중** 구간이에요. 압박이 클 때는 **흐려지는 쪽**으로 기우는 편이에요."
- 내부 점수(1~7)는 저장만 하고 화면에 보이지 않아요 (DT-4). 재측정(DT-6, 4주)과 보석 상태(MR-1) 기준선으로 써요.

## 2. 지키는 원칙

1. **진단 아님.** 진단·검사 결과·우울·점수·레벨·등급 같은 말을 쓰지 않아요 (PRD §8, 콘텐츠 가이드라인 용어표).
2. **발달 수준 8·9단계는 재지 않아요.** 문항은 건강(1~3) · 평균(4~6) · 평균 아래쪽~7단계의 일상 행동까지만 다뤄요. 그보다 깊은 상태는 성격 문항이 아니라 **도움 안내**의 영역이에요 (§5 C5).
3. **행동 빈도로 물어요.** "나는 ~한 사람이다"(성격)가 아니라 "최근 2주 동안 ~했어요"(상태)로 물어요.
4. **흐려짐 문항도 부끄럽지 않게.** 누구나 지친 주에는 할 수 있는 행동으로 써요. 도덕적 판단이 담긴 말(이기적, 거짓말쟁이 등)은 쓰지 않아요.
5. **결과의 흐려짐은 항상 회복 문장으로 끝나요** (MR-4, "흐려짐은 벌이 아니다").

## 3. 구성 (한 사람이 푸는 문항 20개, 약 4분)

| 묶음 | 개수 | 형식 | 재는 것 |
|---|---|---|---|
| A. 요즘의 나 | 유형별 12개 (빛남 4 · 연마 중 4 · 흐려짐 4) | 행동 빈도 4단계 | 평소 구간 |
| B. 이런 장면이라면 | 유형별 3개 | 세 가지 반응 중 고르기 | 압박 속 경향 |
| C. 요즘 나를 둘러싼 것 | 공통 5개 | 4단계 고르기 | 쉼·몸·기댈 곳 보정, 도움 안내 |

- A 문항은 화면에서 **섞어서** 보여줘요 (빛남·연마 중·흐려짐이 묶여 보이지 않게). 아래 표의 순서는 작성용이에요.
- B 문항의 선택지 순서도 문항마다 섞어요.

### 응답 척도 (A)

질문 머리말: **"최근 2주 동안 얼마나 자주 있었나요?"**

| 선택지 | 값 |
|---|---|
| 거의 없었어요 | 0 |
| 가끔 있었어요 | 1 |
| 자주 있었어요 | 2 |
| 거의 매일 있었어요 | 3 |

## 4. 점수 계산 (초안 — 파일럿 뒤 기준값 조정)

```text
L = 빛남 4문항 평균 (0~3)
M = 연마 중 4문항 평균 (0~3)
D = 흐려짐 4문항 평균 (0~3)

raw = 2D + M − 2L                    // 범위 −6 ~ 9
s   = 1 + (raw + 6) × 6 / 15         // 내부 점수 1 ~ 7
c   = C1~C4 평균 (0~3, 클수록 쉼·여유가 부족)
c ≥ 2 이면 s += 0.5 (최대 7)

구간:  s < 3.5 → 빛남 · 3.5 ≤ s < 5.5 → 연마 중 · s ≥ 5.5 → 흐려짐
```

**압박 속 경향 (B 3문항)**
- 흐려짐 반응 2개 이상 → "압박이 클 때는 흐려지는 쪽으로 기우는 편이에요"
- 빛남 반응 2개 이상 → "압박 속에서도 빛을 지키는 편이에요"
- 그 밖 → "압박이 클 때는 연마 중 쪽으로 기우는 편이에요"

**손으로 확인한 예**

| L · M · D | s | 구간 |
|---|---|---|
| 3 · 1 · 0 | 1.4 | 빛남 |
| 1.5 · 2 · 1 | 3.8 | 연마 중 |
| 1 · 2 · 2 | 5.0 | 연마 중 |
| 0.5 · 2.5 · 2.5 | 6.0 | 흐려짐 |

> 기준값 3.5 / 5.5와 C 보정 0.5는 근거 없는 첫 값이에요. 파일럿에서 "결과가 요즘 나와 비슷한가요?" 응답과 맞춰 조정해요.

## 5. C. 요즘 나를 둘러싼 것 (공통 5문항)

| # | 질문 | 선택지 (값 0 → 3) |
|---|---|---|
| C1 | 최근 2주 동안 잠과 쉼은 어땠나요? | 잘 쉬었어요 · 대체로 괜찮았어요 · 자주 부족했어요 · 거의 쉬지 못했어요 |
| C2 | 하루를 보낼 몸의 힘은 어땠나요? | 넉넉했어요 · 괜찮았어요 · 자주 바닥났어요 · 거의 늘 바닥이었어요 |
| C3 | 힘들 때 이야기할 사람이 있나요? | 여럿 있어요 · 한두 명 있어요 · 있지만 말하기 어려워요 · 떠오르지 않아요 |
| C4 | 나를 위해 쓴 시간은 어땠나요? | 충분했어요 · 조금 있었어요 · 거의 없었어요 · 전혀 없었어요 |
| C5 | 요즘 마음의 짐은 어느 정도인가요? | 가벼운 편이에요 · 감당할 만해요 · 무거워요 · 일상을 버티기 어려울 만큼 무거워요 |

**C5에서 마지막 선택지를 고르면**
- 결과 맨 위에 도움 안내를 먼저 보여줘요. 문구는 다이어리 위기 안내(SF-2)와 같은 고정 문구, 109 · 1577-0199 · 112·119.
- 그 화면에서는 보석 연출, 리포트·결제 안내, 공유 버튼을 보여주지 않아요 (SF-3).
- 상태 결과는 그 아래에 그대로 보여줘요 (판정을 숨기면 오히려 더 불안할 수 있어서). → **검토 필요: 결과를 아예 보류할지**
- C5는 성격 점수에 넣지 않아요. 위기 선별 척도(PHQ 등)가 아니라 안내를 띄우기 위한 문항이에요.
