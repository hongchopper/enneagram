### 0-1. 글 한 편의 모양 (모든 글 공통)

화면 순서는 하나로 고정이에요. 포맷(F1~F8)이 달라도 이 틀 안에서 바뀌어요.

```
사진 → 분류 → 제목 → 리드(열기) → 본문(보여주기·풀어주기) → [참여: 퀴즈 / O·X / 체크 미션]
→ 스스로 물어볼 질문(1~2개) → 이번 주 해볼 것(1개) → 근거(연구 글만) → 안내(민감한 글만) → 이어 읽기
```

| 칸 | 규칙 |
|---|---|
| 제목 | 18자 안팎(유형 이름 포함 최대 20자). 9-3 제목 공식. 물음표·느낌표는 1개까지 |
| 리드 | 열기. 1~2문장, 80자 이내. "어, 내 얘기네" 하는 장면이나 질문으로 |
| 본문 | 블로그형. `h2` 소제목 3~4개 + 문단(2~4문장) + 목록. 문장 40자 안팎. **700~1200자** (2026-10-08, 500자 안팎은 짧다는 피드백) |
| 톤 (2026-10-08) | 감성 위로보다 **재미와 공감**: “어, 내 얘기네” 하는 구체적 장면(검색 기록, 장바구니, 단톡방), 가벼운 비유(경보기, 통장, 동굴), 주변에서 보이는 모습, 바로 해볼 방법. ‘천천히 읽어 봐요’, ‘괜찮아요’ 반복 같은 다독임은 줄여요 |
| 참여 | 연구 글은 포맷에 맞게 하나: 퀴즈(F3) · O/X(F4) · 체크 미션(F8). 고르면 바로 아래에 해설이 보여요 (펼치기 아님) |
| 질문 | 열린 질문 1~2개. "왜" 대신 "무엇·언제·어떤" |
| 해볼 것 | 5분 안에 할 수 있는 행동 1개. `~해보는 건 어때요?` 또는 `~해 보기` |
| 근거 | 5장 신뢰도 템플릿 문장 + `출처: 저자(연도), 매체` |

데이터: 유형별 글은 `content/type-posts.js`, 새로 쓴 글·연구 글은 `content/explore-posts.js`의 `ARTICLES`. 쓴 뒤 `node tools/content-check.js`로 길이·말투·금지어를 확인해요.

## 1. 한눈에 보기

**콘텐츠의 역할은 하나예요: "재밌어서 들어왔다가, 나를 들여다보게 되는 것."**

```
[밖] 공감·재미 콘텐츠 ──▶ 간이 검사 ──▶ 프로필 카드 공유 (무료)
                                │
[안] 성찰 콘텐츠 ◀── 테마 다이어리·맞춤 솔루션·리포트 (유료)
```

| PRD 페르소나 | 이 사람에게 먹히는 콘텐츠 | 목표 행동 |
|---|---|---|
| 호기심형 (20대) | 숫자로 보는 보석, 반전 카드, 희귀도, MBTI 매핑 | 간이 검사 시작, 카드 공유 |
| 성찰형 (20~30대) | 회복 처방, 성장 방향, 자기 vs 타인 인식 | 상세 검사, 다이어리 시작 |
| 생활 테마형 (30대 직장인·양육자) | 일·돈·연애·육아 사용설명서 | 테마 다이어리 구독 |

## 2. 콘텐츠 4축 (비율)

| 축 | 비율 | 무엇 | 대표 소재 (소재집 기호) |
|---|---|---|---|
| **공감** 💎 "맞아 나야" | 40% | 유형별 일상·습관·숫자 | 텅장 사유(G2), 반전 연애(F1), 부부싸움(C1), 공부·운동(I) |
| **성찰** 🪞 "나를 들여다보기" | 30% | 질문, 회복법, 성장 방향 | 회복 처방(B2), 시트린 빛 빌리기(B3), 성장 방향 책(D4) |
| **세계관** ✨ "보석의 비밀" | 20% | 보석·색·캐릭터 이야기 | 보석 컬러(D5), 보석 수호자 9인(D2), 희귀도(E3) |
| **신뢰** 🔬 "솔직하게 말할게요" | 10% | 에니어그램이 뭔지, 근거의 한계 | 과학일까?(E2), 먼저 맞혀보기(E1) |

- **공감으로 데려오고, 성찰로 붙잡아요.** 공감 콘텐츠만 많으면 "또 하나의 성격 테스트 계정"이 되고, 성찰만 많으면 무거워져요.
- 신뢰 콘텐츠는 적게, 하지만 **고정 게시물(프로필 상단)**에 꼭 둬요.

## 4. 보이스 & 톤

### 4-1. 우리는 이런 사람처럼 말해요
**"보석을 잘 아는 다정한 친구."** 판정하는 선생님도, 들뜬 점술가도 아니에요.

| 이런 말투 ✅ | 이런 말투 ❌ |
|---|---|
| 성별 없는 다정한 존댓말 ("~해요") | 반말 강요, "~했쪙", "소녀/공주/언니" |
| 보석·빛·결정 은유 ("빛이 흐려진 날") | 의학·진단 표현 ("우울 위험", "증상") |
| "~하는 경향이 있어요", "~일 수도 있어요" | "4번은 무조건 ~해요" (단정) |
| 약점도 빛의 다른 면으로 ("섬세해서 지치기 쉬워요") | 조롱·비하 ("4번은 돈을 못 벌어요 ㅋㅋ") |
| 가볍게 웃기되 마지막엔 나를 돌아보는 질문 | 웃기고 끝 (자극만) |

### 4-2. 단어장

| 쓰는 말 | 피하는 말 | 이유 |
|---|---|---|
| 보석 컨디션, 마음 상태, 빛남·연마 중·흐려짐 | 진단, 검진, 레벨, 등급, 점수 | PRD §8 "진단 아님" 원칙 |
| 성찰, 들여다보기, 돌아보기 | 치료, 처방전(의학적 맥락), 개선 | 의료 표현·스토어 심사 |
| 보석 (사파이어·로즈쿼츠…) + 번호 병기 | 번호만 ("4번은~") | 브랜드 각인. 첫 등장은 "오팔(4번)" |
| 결, 빛, 단면, 원석 | 결함, 불량, 깨짐 | 디자인 원칙 "흐려짐은 벌이 아니다" |
| 양육자 | 엄마 (일반 문맥) | 성별 중립 |
| 경향, 데이터에서는 | 사실, 과학적으로 증명된 | 근거 수준이 대부분 🟡 |

### 4-3. 예시로 보기

❌ "오팔(4번)은 연애를 제일 못해요 ㅋㅋㅋ 연봉도 꼴찌!"
✅ "로맨틱한 이미지의 오팔(4번), 사실 연애할 때 가장 마음이 복잡한 보석이래요. 깊이 느끼는 만큼 쉽게 채워지지 않거든요. 💭 당신이 관계에서 진짜 원하는 빛은 뭔가요?"

❌ "당신의 스트레스 레벨을 진단해드려요."
✅ "요즘 내 보석, 얼마나 빛나고 있을까요?"

## 5. 근거 표기 규칙

소재집의 신뢰도 표시에 따라 문장을 다르게 써요.

| 신뢰도 | 문장 템플릿 | 예 |
|---|---|---|
| 🟢 검증 | "○○ 연구에 따르면 ~" | "대학생 781명을 조사한 연구에 따르면 가슴형 보석은 털어놓을 때 행복이 커졌어요." |
| 🟡 일부 근거 | "한 조사에서는 ~", "~라는 데이터도 있어요" | "미국 성격검사 사이트 사용자 5만 8천 명 설문에서는…" |
| 🔴 이론·해석 | "에니어그램에서는 ~라고 봐요" | "에니어그램에서는 6번이 9번 방향으로 성장한다고 봐요." |

**출처 표기 형식**
- 카드뉴스: 마지막 장 하단 `caption` 크기로 `출처: 저자(연도), 학술지명` / 설문은 `출처: Truity 사용자 설문(2023, n=81,683)`
- 블로그: 본문 끝에 링크 포함 전체 출처
- 릴스·쇼츠: 마지막 1초 화면 + 캡션에 출처
- 숫자는 반올림해도 원래 의미가 바뀌지 않게 ("51%" → "절반 이상" OK, "65%" → "대부분" ❌)

**인용 범위 (저작권, 소재집 0장 요약)**
- 결과·수치를 **우리 말로 다시 쓰기** ✅ / 논문 문장·표·그래프 **그대로 복사** ❌
- 그래프는 우리 디자인으로 새로 그리기
- 타사 검사 문항·이름(RHETI, KEPTI, iEQ9) 사용 ❌, 책 속 유형 설명 문장 그대로 ❌ (PRD 7-4)

## 6. 9보석 공평 원칙

1. **순위표 금지.** "연봉 1위~9위", "최악의 연애 유형" 같은 서열 형식은 쓰지 않아요. 같은 데이터라도 "보석마다 돈을 대하는 이유"로 풀어요.
2. **시리즈는 9보석을 모두 다뤄요.** 특정 보석만 웃음거리가 되지 않게.
3. **한 보석 = 빛 + 그림자 + 질문.** 강점 하나, 흔들리는 지점 하나, 돌아볼 질문 하나를 세트로.
4. **불리한 데이터는 재해석하거나 빼요.** 예: 오팔(4번)의 낮은 소득 → "돈보다 의미를 좇는 보석". 재해석이 억지라면 그 항목은 빼요.
5. **성별 차이 데이터는 강조하지 않아요.** ("1번은 남자가 많다" 등) 성별 중립 방향과 충돌.

| 세일러문·카드캡터 체리 등 실제 IP 캐릭터·로고·의상 | PRD §5-5 IP 원칙 |
| 궁합 판정 ("4번과 8번은 최악") | 판정 X, 성찰 O. "둘이 함께 빛나는 법"으로 |

## 9. 앱 안 글 형식

> **같은 보석함, 다른 보석.** 앱 안의 글은 어느 화면에서 읽어도 "이 앱 글이네" 하고 알아볼 수 있어야 해요. 그렇다고 모든 글이 똑같은 모양이면 금방 지루해져요. 그래서 **꼭 지킬 것은 적게, 바꿔도 되는 것은 넉넉하게** 정해뒀어요.

### 9-1. 꼭 지킬 것 vs 자유롭게 바꿀 것

| 🔒 꼭 지킬 것 (우리 앱의 지문) | 🎨 자유롭게 바꿀 것 (글마다 다르게) |
|---|---|
| 목소리: 다정한 친구의 해요체 (4장). 편지·대화 속 보석의 말만 예외 | **포맷**: 9-5 메뉴에서 골라요 (이야기, 퀴즈, 편지, 대화…) |
| **나로 열고, 질문이나 미션으로 닫기** (9-2) | 여는 방식: 장면, 질문, 숫자, 퀴즈, 편지 첫 줄 |
| 단어장과 금지어 (4-2, 7장) | 소제목, 문장 리듬, 말투의 장난기 정도 |
| 연구는 근거 표기, 해석은 해석이라고 밝히기 (5장) | 중간 순서: 반전 → 해석 → 또 반전도 OK |
| 9보석 공평 원칙 (6장) | 참여 요소: 체크박스, 선택지, O/X, 한 단어 답하기 |
| 아이콘의 뜻 (💭은 늘 질문, 🌱은 늘 해볼 것) | 이모지 양 (9-6 범위 안에서) |
| 길이 상한과 문장 40자 (9-4) | 분량 (범위 안에서 짧게도 길게도) |
| 출처·고지 위치 (맨 아래) | 보석이 직접 말하기, 대화, 편지 같은 시점 |

**다양성 규칙**
1. **같은 포맷을 2편 연속 쓰지 않아요.**
2. **한 달에 포맷 4가지 이상**을 섞어요.
3. **여는 문장 패턴도 돌려가며.** "~한 적 있나요?"로 시작하는 글이 연속되지 않게.
4. 새로운 포맷을 시도해도 좋아요. 9-1 왼쪽 칸만 지키면 돼요. 반응이 좋으면 9-5 메뉴에 추가해요.

### 9-2. 뼈대: 4단 흐름

모든 글 밑에는 같은 흐름이 깔려 있어요. 기승전결을 우리 서비스에 맞게 바꾼 거예요. **겉모양(포맷)은 달라도 이 흐름은 남아 있어야 해요.**

| 단계 | 이름 | 하는 일 | 독자 마음 |
|---|---|---|---|
| 기 | **열기** | 나와 연결되는 순간으로 시작 | "어, 내 얘기네" |
| 승 | **보여주기** | 보석 관점의 사실, 데이터, 반전 | "그렇구나, 신기하다" |
| 전 | **풀어주기** | 그게 나에게 무슨 뜻인지 (빛과 그림자) | "아, 그래서 내가 그랬구나" |
| 결 | **돌려주기** | 질문이나 해볼 것을 건넴 | "나는 어떨까? 해볼까?" |

**흐름 규칙**
1. **기로 열고 결로 닫는 것만 고정.** 승과 전은 오가도 괜찮아요 (반전 → 해석 → 또 다른 반전).
2. **결은 반드시 있어요.** 정보만 주고 끝나는 글은 없어요.
3. **빛이 그림자보다 먼저.** 그림자로 끝나지 않게.
4. **한 글 = 한 메시지.** 쓰기 전에 "이 글을 한 문장으로 말하면?"을 먼저 적어요.
5. **짧은 글은 단계를 줄여요.** 푸시는 기+결, 솔루션은 기·승·결.

### 9-3. 제목 공식

공식은 **출발점**이에요. 18자와 금지어만 지키면 벗어나도 괜찮아요.

| 공식 | 틀 | 예 |
|---|---|---|
| ① 질문형 | `[보석/나]는 왜 [행동]할까?` | 에메랄드는 왜 비상금이 있어야 안심할까? |
| ② 반전형 | `[통념], 사실은 [반전]` | 로맨틱한 오팔, 사실 연애가 제일 복잡해요 |
| ③ 방법형 | `[보석]이 다시 빛나는 법` | 가슴형 보석이 다시 빛나는 법 |
| ④ 상태형 | `[보석] + [지금 상태]` | 루비를 다듬는 중이에요 |
| ⑤ 이름형 | `[수식어], [보석]([번호])` | 단단한 불꽃, 루비(8번) |
| ⑥ 대사형 | `"[누구나 해본 말]"` | "괜찮아"가 입버릇인 보석들 |
| ⑦ 초대형 | `오늘은 [보석]처럼 [해보기]` | 오늘은 시트린처럼 놀아봐요 |

**제목 규칙**
- 길이 **18자 이내**, 푸시 제목은 15자.
- 보석 이름이 들어가면 좋아요 (내 보석이면 바로 눌러보게 돼요).
- 숫자는 1개까지.
- 피하기: 과장("충격", "소름"), 판정("최악의", "1위"), 물음표·느낌표 두 개 이상.

| ❌ | ✅ | 왜 |
|---|---|---|
| 4번 유형의 연애 특징 분석 | 로맨틱한 오팔, 사실 연애가 제일 복잡해요 | 딱딱함 → 반전형 |
| 충격! 연봉 꼴찌 유형은? | 오팔이 돈보다 좇는 것 | 순위·조롱 금지 |
| 스트레스 관리법 | 가슴형 보석이 다시 빛나는 법 | 보석 은유 + 방법형 |

### 9-4. 분량과 문단

**문장·문단**
- 한 문장 **40자 이내**. 넘으면 둘로 나눠요.
- 한 문단은 **한 생각, 2~3문장**.
- 어려운 말은 쉬운 말로 ("자기 효능감" → "나도 할 수 있다는 느낌").

**글 길이 4가지**

| 크기 | 글자 수 | 쓰는 곳 | 읽는 시간 |
|---|---|---|---|
| **S 한 줄** | 60자 이내 | 푸시, 오늘의 보석 상태, 빈 화면, 다이어리 질문 | 5초 |
| **M 카드** | 150~250자 | 맞춤 솔루션, 패턴 알림, 검사 결과, 성장 연습 | 30초 |
| **L 노트** | 500~900자 | 보석 노트(읽을거리), 유형 설명, 월간 회고 | 2분 |
| **자세히 보기** | 1,500~2,500자 | L 노트 아래 "자세히 보기"로 이어지는 긴 이야기 | 4분 |

L 노트는 스크롤 3번 안에 끝나게. 자세히 보기는 소제목마다 스크롤 한 번 정도.

### 9-6. 친근하게 쓰는 규칙

어떤 포맷이든 **"친구가 재밌는 얘기를 들려주는 느낌"**이 기준이에요. 보고서처럼 읽히면 다시 써요.

1. **소제목은 말 걸듯이.** "결과" ❌ → "결과는 살짝 반전이었어요" ✅
2. **다음이 궁금하게.** 한 단락이 끝날 때 다음 단락의 궁금증을 남겨요.
3. **숫자는 글 전체에 2~3개만.** 나머지는 "꽤", "훨씬" 같은 말로.
4. **표는 앱 안 글에 쓰지 않아요.** 비교는 한 줄 대사, 선택지, 짧은 목록으로.
5. **한계는 "🔍 솔직히 말하면" 한 문단으로.** 숨기지 않되 무겁지 않게.
6. **독자가 참여할 거리 1개** (포맷별 참여 요소 참고).
7. **연구와 해석은 구분.** 해석 끝에 *(여기는 우리가 생각해본 해석이에요.)*

**L 노트·자세히 보기에서 풀리는 것:** 소제목 아이콘, 문단당 이모지 1개, 섹션당 느낌표 1개, 대사·편지 속 구어체. 하트 이모지와 이모지 나열은 여전히 ❌.

### 9-7. 쓰고 나서 확인

1. 한 문장 메시지가 제목과 마지막에 모두 드러나나요?
2. 마지막이 질문이나 해볼 것으로 끝나나요?
3. 소리 내어 읽었을 때 숨찬 문장(40자 초과)이 없나요?
4. 보고서처럼 읽히는 부분이 없나요? (표, 번호 매긴 결과, "~를 시사합니다")
5. 최근 글 2편과 포맷·여는 방식이 겹치지 않나요?

### 9-8. 공통 문장 규칙

| 항목 | 규칙 | 예 |
|---|---|---|
| 말투 | 해요체 하나로 통일. 합쇼체(~합니다)·반말 섞지 않기 | "빛나고 있어요" ✅ / "빛나고 있습니다" ❌ |
| 호칭 | 이름이 있으면 `[닉네임]님`, 없으면 호칭 생략. "당신"은 앱 안에서 쓰지 않음 | "선미님의 보석은" / "오늘 마음은 어땠나요?" |
| 보석 표기 | 본문 첫 등장 `보석이름(번호)`, 이후 보석이름. 제목엔 번호를 넣지 않고, 이름형 제목(9-3 ⑤)만 예외 | "루비(8번)는… 루비가…" |
| 문장 끝 | 서술은 `~요`, 질문은 `~나요? / ~까요?`, 제안은 `~해보는 건 어때요?` | |
| 느낌표 | 한 화면에 1개까지 (L 노트·자세히 보기는 9-6 예외) | |
| 이모지 | 본문 안에선 쓰지 않음. **블록 아이콘(9-9)만** 사용 (L 노트·자세히 보기는 9-6 예외) | |
| 굵게 | 블록당 1곳까지 (보석 이름 또는 핵심 단어) | |
| 숫자·날짜 | 아라비아 숫자, `10월 6일 (월)`, 기간은 `이번 주 / 이번 달` | |
| 한 줄 길이 | 34자 안팎에서 자연스럽게 줄바꿈 (디자인 시스템 본문 기준) | |
| 금지어 | 4-2 단어장 그대로 (진단, 점수, 레벨, 등급, 위험, 치료, 증상) | |

### 9-9. 블록 사전

앱 안 글은 아래 블록만으로 만들어요. 글자 수는 M 카드 기준이고, L 노트·자세히 보기는 9-4 분량과 9-5 포맷을 따라요. **S·M 글과 F1 블록형은 이 표의 위→아래 순서를 지켜요**(건너뛰기 OK). 다른 포맷(F2~F8)은 아이콘의 뜻만 지키면 순서와 모양을 자유롭게 써요.

| 순서 | 블록 | 아이콘 | 역할 | 글자 수 | 문장 틀 | 타이포 |
|---|---|---|---|---|---|---|
| 0 | 머리표 | - | 어디·언제인지 | 20자 | `[테마/화면] · [날짜]` | `caption` |
| 1 | 제목 | - | 이 글의 한 줄 | 18자 | 명사형 또는 짧은 문장 | `h2` |
| 2 | 공감 | 🤍 | 마음 받아주기 | 40자 | `~였군요. / ~했겠어요.` | `body` |
| 3 | 관찰 | 🔍 | 보석 관점에서 보인 것 | 60자 | `~하는 모습이 보였어요.` (근거가 된 사실을 함께) | `body` |
| 4 | 빛 | ✨ | 강점 | 40자 | `~할 줄 알아요.` | `body` |
| 5 | 그림자 | 🌫 | 흔들리는 지점 | 40자 | `~할 때 흔들리기 쉬워요.` | `body` |
| 6 | 질문 | 💭 | 스스로 돌아볼 질문 | 30자 | 열린 질문. `왜` 대신 `무엇·언제·어떤` | `body` Bold |
| 7 | 작은 연습 | 🌱 | 5분 안에 할 수 있는 행동 1개 | 40자 | `~해보는 건 어때요?` | `body` |
| 8 | 근거 | 📎 | 연구·데이터 한 줄 (선택) | 50자 | 5장 신뢰도 템플릿 | `sub` |
| 9 | 고지 | ⓘ | AI 결과 안내 (AI 글은 필수) | 고정 | `자기 성찰을 돕는 참고 의견이에요.` | `caption` |
| 10 | 버튼 | - | 다음 행동 | 8자 | 동사로 끝 `다이어리 쓰기` | `button` |

**블록 디자인 고정값**
- 아이콘은 블록 제목 자리 왼쪽에 16px, 색은 그 사용자 보석의 `deep`.
- 블록 사이 간격 16px, 블록 묶음(카드) 사이 24px.
- 질문(💭)과 작은 연습(🌱)은 항상 보석 `soft` 배경의 둥근 칩 박스 안에 넣어서 "내가 할 것"이 눈에 띄게.
- 고지(ⓘ)는 항상 카드 맨 아래, 버튼 위.

### 9-12. AI가 쓰는 글의 출력 양식

맞춤 솔루션(A6), 패턴 알림(A7·A8), 회고(A11)는 AI가 쓰기 때문에 형식이 쉽게 흔들려요. AI에게는 **문장이 아니라 블록 단위 JSON**으로 받아서, 앱이 9-9 디자인에 맞춰 조립해요. 글자 수를 넘거나 블록이 빠지면 앱에서 다시 요청해요.

```json
{
  "template": "A6",
  "gem": 8,
  "blocks": {
    "empathy": "혼자 마감을 다 챙기느라 하루가 길었겠어요.",
    "observation": "\"내가 안 하면 아무도 안 해\"라는 마음이 오늘 일기에 보였어요.",
    "question": "그때 누군가에게 바랐던 건 무엇이었나요?",
    "practice": "내일 한 가지 일만 동료에게 부탁해보는 건 어때요?"
  }
}
```

AI 프롬프트에 넣을 규칙(요약): 9-8 문장 규칙, 9-9 글자 수와 문장 틀, 4-2 금지어, "관찰은 일기에 실제로 있는 내용만", "질문은 1개, 작은 연습은 1개". 고지(ⓘ)는 AI가 쓰지 않고 앱이 항상 붙여요.

## 11. 제작 공정

1. **소재 고르기**: 소재집에서 고르고 4축 비율 확인
2. **신뢰도 확인**: 🟡는 원문을 한 번 확인 (못 하면 "한 조사에서는"으로 낮춰 쓰기)
3. **우리 말로 쓰기**: 4장 톤, 6장 공평 원칙 적용
4. **9보석 버전 만들기**: 빛 + 그림자 + 질문
5. **포맷 고르고 쓰기**: 앱 안 글은 9장(9-5 포맷 메뉴에서 고르고 4단 흐름으로), SNS는 10장 템플릿. 8장 비주얼 규칙 적용
6. **발행 전 체크리스트** (12장) 통과
7. **재활용**: 릴스·스레드·블로그·앱 내 질문으로 쪼개기
8. **기록**: 성과(14장)와 함께 콘텐츠 목록에 남기기

| 도달 | 저장 수, 공유 수 (좋아요보다 중요) | 공감 콘텐츠는 "저장·공유"가 진짜 반응 |
| 유입 | 프로필 링크 클릭 → 간이 검사 시작률 | 콘텐츠가 서비스로 이어지는지 |
| 확산 | 프로필 카드 공유 수 | PRD 무료 퍼널의 핵심 |
| 리텐션 | 앱 내 질문 → 다이어리 작성률 | 성찰 콘텐츠의 역할 |
| 장기 | 자체 "보석 리포트" 언론·커뮤니티 인용 | 브랜드 신뢰 |

## 15. 정해야 할 것

| 항목 | 기본안 |
|---|---|
| 서비스 이름·계정 이름 | 미정 (PRD에서 아직 가칭) |
